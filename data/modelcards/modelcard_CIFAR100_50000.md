# Model Card for CIFAR100_50000

This is a diffusion ensemble consisting of 22 independently trained components, trained on a subset of the CIFAR-100 dataset containing 50000 images.

## Model Details

### Model Description

- **Developed by:** Zheng Dai
- **Model type:** Diffusion Ensemble
- **Language(s) (NLP):** Not a language model
- **License:** Apache-2.0

## Uses

This is a research model for studying the attributability of samples generated by diffusion models. The ensemble can generate images and constituent models may be ablated away to remove the causal influence of any single image in the training data.

### Direct Use

This model can be used directly to generate synthetic images. Given the same noise trajectory used to generate the synthetic image, it can also be used to generate the counterfactual sample that would have been generated had some image that was factually present in the data been omitted.

### Out-of-Scope Use

This model is not intended to be used for any purpose outside of factual or counterfactual image generation.

## Bias, Risks, and Limitations

This model is expected to inherit biases from the dataset upon which it is trained.

### Recommendations

This model is not intended for use outside of a research context.

## Training Details

### Training Data

This model was trained on a subset of the CIFAR-100 dataset containing 50000 images. The Dataset Card can be found at https://huggingface.co/datasets/uoft-cs/cifar100.

### Training Procedure

Models are trained by predicting denoised images using the scheme proposed in [“Denoising diffusion probabilistic models”](https://arxiv.org/abs/2006.11239).

#### Training Hyperparameters

- **Training regime:** 1000 possible noise levels were used for training. Random horizontal flipping was used as a data augmentation strategy. Adam was used for gradient descent with [default PyTorch parameters](https://docs.pytorch.org/docs/2.11/generated/torch.optim.Adam.html), a learning rate of 0.0001, and a batch size of 128. A dropout of 0.1 was applied.

## Evaluation

### Testing Data, Factors & Metrics

#### Testing Data

This Frechet Inception Distance (FID) from a the [CIFAR-100 image distribution](https://huggingface.co/datasets/uoft-cs/cifar100) was calculated.The distribution was determined using a held out subset disjoint from the training data.

#### Factors

The distribution of CIFAR-100 was determined using a split disjoint from the training data.

#### Metrics

Frechet Inception Distance.
